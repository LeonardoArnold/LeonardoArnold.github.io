# Leonardo Arnold — Portfólio

Portfólio pessoal de **Leonardo Arnold**, estudante de Engenharia de Software e desenvolvedor Full Stack em formação.

## Projeto em destaque: El Patrón

O principal projeto apresentado neste portfólio é o **El Patrón — Sistema de Cardápio Digital**, uma aplicação web desenvolvida para uma hamburgueria e conveniência de São Miguel do Iguaçu/PR.

O sistema possui cardápio para o cliente, gestão de pedidos e painel administrativo. O projeto foi estruturado como uma aplicação Full Stack, com frontend em React, backend/API em Flask, PostgreSQL e infraestrutura de produção em VPS com Docker.

### Stack do El Patrón

- **Backend/API:** Python 3.11, Flask 3.1, Flask-SQLAlchemy, Flask-Login e Flask-WTF
- **Frontend:** React 19 e Vite
- **Banco:** PostgreSQL 17
- **Migrations:** Flask-Migrate e Alembic
- **Servidor/TLS:** Caddy 2, HTTPS automático e HTTP/2
- **Infra:** VPS Hostinger, Ubuntu 24.04 e Docker Compose
- **Observabilidade:** Sentry
- **Backup:** pg_dump, retenção e Backblaze B2
- **Testes/CI:** Pytest, Vitest, Playwright e GitHub Actions
