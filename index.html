PROJETO EM DESTAQUE

El Patrón — Sistema de Cardápio Digital

Projeto publicado

Sistema web de cardápio digital e gestão de pedidos para a hamburgueria e conveniência El Patrón, em São Miguel do Iguaçu/PR.

O cliente monta o pedido pelo celular e a operação conta com um painel administrativo para gerenciamento. O projeto foi pensado como uma aplicação real, com backend, API, banco de dados, frontend separado e infraestrutura de produção.

Arquitetura

O backend é uma aplicação monolítica em Flask com painel administrativo e API. O cardápio do cliente é desenvolvido em React e o PostgreSQL armazena os dados. Em produção, os componentes são executados em containers Docker, com o Caddy na frente fazendo HTTPS e encaminhamento das requisições.

Engenharia

O projeto utiliza migrations, testes automatizados, CI, monitoramento de erros e rotina de backup. A documentação do repositório também registra comandos para ambiente local, testes e operação.
