PROJETO EM DESTAQUE

El Patrón

Sistema de cardápio digital e gestão de pedidos

Publicado

Sistema web desenvolvido para a hamburgueria e conveniência El Patrón, em São Miguel do Iguaçu/PR.

O cliente monta o pedido pelo celular e a operação conta com um painel administrativo para gerenciamento. O projeto foi pensado como uma aplicação real, com frontend separado, backend/API, banco de dados e infraestrutura de produção.

VISÃO TÉCNICA

Como o projeto é estruturado

Frontend React 19 + Vite
→
Backend / API Python + Flask
→
Banco PostgreSQL 17
→
Produção Docker + VPS + Caddy

O backend é uma aplicação monolítica em Flask com painel administrativo e API. O PostgreSQL armazena os dados e os componentes são executados em containers Docker. O Caddy fica na frente da aplicação, cuidando de HTTPS e encaminhamento das requisições.

ENGENHARIA

Projeto pensado para produção

O projeto utiliza migrations, testes automatizados, CI, monitoramento de erros e rotina de backup. A documentação do repositório registra comandos para ambiente local, testes e operação.

RESULTADO

Aplicação real e publicada

O sistema foi desenvolvido para um negócio local e está disponível em domínio próprio, reunindo desenvolvimento, banco de dados, testes e infraestrutura em um único projeto.
